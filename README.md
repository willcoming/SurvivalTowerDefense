## 本機啟動

需求：Node.js 22.12 以上（實測 22.22.3）及 npm。從本專案資料夾執行：

```sh
npm ci --no-audit --no-fund
npm run build
npm run preview
```

電腦開啟 [本機遊戲](http://localhost:5173/)。手機連上同一個 Wi-Fi，再開啟終端輸出的 `Network` 網址；區網 IP 會隨網路改變，請以當次輸出為準。主機需保持開機且 preview 仍在執行。

開發時使用 `npm run dev`。dev 與 preview 都固定 **5173** 且拒絕自動換埠，只能同時啟動其中一個；先在原終端按 Ctrl+C，再換另一個命令。不要直接雙擊 `index.html`。`dist/` 是建置後的靜態網站；已發布至 [GitHub Pages](https://willcoming.github.io/SurvivalTowerDefense/)。

## 安裝與離線遊玩

用手機或電腦連網開啟 [線上遊戲](https://willcoming.github.io/SurvivalTowerDefense/)，遊戲會在背景自動下載完整離線內容。首頁提示或設定頁顯示 **「可離線遊玩」** 後，就能斷網重開；尚未看過的角色、造型和關卡也包含在內。

支援的瀏覽器可在設定按「安裝遊戲」。iPhone／iPad 使用瀏覽器的「分享 → 加入主畫面」；安裝後先連網開啟一次，確認顯示「可離線遊玩」。沒有安裝按鈕的瀏覽器可依設定頁指引操作，或繼續使用原網址。

下載失敗可在設定重試。新版會在連網時背景下載，完成後關閉所有遊戲視窗再開啟套用，不會中途重載戰鬥。清除網站資料會清除離線內容及存檔；不同瀏覽器或安裝環境不保證共用進度。完整操作、限制與驗收方式見 [離線安裝版](docs/OFFLINE.md)。

## 操作

手機採全螢幕遊戲介面：底部切換主要功能，編隊一屏顯示全部八位隊員、招募數量與出戰人數；章節用切換操作查看，本局技能樹直接顯示完整分支與前置連線。出擊與配點確認保持可見，完整立繪與長篇資訊可點開詳細面板查看。詳見 [手機介面更新](docs/MOBILE_LAYOUT_UPDATE.md)。

1. 選擇關卡並查看敵人情報；編隊卡片標示「已出戰／待命／未招募」與持有造型數。點隊員開啟面板，加入或移出小隊並指定隊長；一般行動可派 1–5 人，四人挑戰最多 4 人。完整技能樹可從角色面板前往圖鑑查看。
2. 點擊「開始行動」。武器自動索敵，隊長加成開場生效；各角色取得終極後獨立冷卻並自動施放，留意敵人的蓄力文字與紅色預警。
3. 每累積 60 經驗取得 2 點，波中不中斷。清完本波及敵方攻擊後，集中配置全部未用點數；點節點暫選，再按「確認配置並繼續」，也可「保留全部點數並繼續」。普通技能 1 點、終極 2 點，可部分使用，剩餘點數留到下一波。本局不洗點，點數不帶入下一場。
4. 每人 24 個節點，交會點任一前置即可解鎖；三個領域可跨路線混搭，普通路線也有獨立封頂。終極最短為 4 點前置加 2 點取得，每人一個；一般行動最多五人各一個，兩終極挑戰最多兩個，禁止終極挑戰不可取得。
5. 一般關卡完成所有常規波次及配點後迎戰 Boss；百波挑戰首領於第 100 波登場。擊破首領並清除殘敵後直接結算，無須花完剩餘點數；防線 HP 歸零則失敗。

戰鬥右上角的速度按鈕依序切換 **1× → 2× → 3× → 1×**，選擇會自動記住。敵我攻擊、移動、冷卻與本波出怪同步加速；配點與暫停時完全停止。下一波等待本波清除及配點確認，不再按全局時間重疊進場。新戰局沒有通關時限，顯示有效戰鬥時間及實際波次進度。

主線常規波數依序為 **10、10、10、10、10、12、13、14、16、17、18、20**，三個支線各 10 波；首領戰另計。系統不設通用波數上限，百波挑戰仍以完成 100 波為目標。技能樹的「已用／本關」代表已消耗與本關總預算，右側另顯示目前可用與確認後保留點數。主線前五關各 20 點，後續 24～32 點，百波挑戰 60 點。舊版戰局保留原規則；永久指揮官獎勵公式維持原樣。

八位角色的原裝與夏日裝，共 16 套形態均使用 12 格精緻 Q 版動畫：六格普攻與六格隊長技能。角色以身體高度統一尺度，身高差約 4%，同角色換裝維持相同比例。舊版隊長技能動畫素材保留；目前新局的隊長為被動加成，終極自動在戰場施放，沒有切入過場或凍結戰鬥。技能樹終極留在戰場內呈現，預警保持最高圖層，密集戰鬥自動縮減裝飾特效。敵我子彈、砲彈、狙擊彈及微型飛彈使用實體彈藥素材，電弧與槍口火焰使用繪製素材；不以線段、圓環、多邊形或光暈代替彈體。

新戰局加入近／中／遠射程：雷娜、米菈為近程，璃音、希雅為中程，凜月、芙蕾為遠程。點擊下方角色頭像可切換射程覆蓋，再點一次關閉；目標尚未進入射程時會顯示等待。爆炸邊界對應實際作用範圍，敵人身上的火焰、緩速環、暈眩符號與曝露框跟隨實際狀態；持續傷害按裝備形態顯示屬性顏色與名稱，合併顯示已造成的傷害。

三位 Boss 各有警示、傳送門、現身與名稱演出，固定約 **1.5 秒現實時間**，期間戰鬥、倒數與冷卻全部暫停，之後自動恢復。現行版本的 Boss 登場時同步帶入 **42 隻小怪**，從上方分六排湧入；這批援軍每隻提供 1 經驗，共 42 經驗，已計入本關技能點總預算；持續召喚的小怪不提供經驗，且必須一併清除才算勝利。3× 不縮短出場時間；同一戰局內暫停後能接續剩餘演出，不會重複生成援軍；重新載入則結束本局。詳見 [射程與戰鬥可讀性更新](docs/COMBAT_READABILITY_UPDATE.md)。

目前新局不提供手動隊長技能或自動施放開關。每位角色的終極取得後先完成一次冷卻，再於條件符合時自動施放；暫停與配點時停止計時。舊版戰局仍依原版本規則處理。

八種敵人與三隻 Boss 均使用 16 格動作，包含待機、六格移動、蓄力、出手、受擊與三階段倒下。3× 下步態有可讀性上限，實際移動與攻擊時序仍同步加速。

桌面可按 Escape 暫停；技能樹支援方向鍵、加減鍵、Home 回到起點、0 全覽。所有選項也可用鍵盤 Tab 操作。手機切背景或橫放時暫停，返回後需確認繼續。暫停／配點時間不計入有效戰鬥時間。

## 星際夏日招募

主線 12 關＋夏日支線 3 關各首通 1 張券；主線每關另有四人、禁止終極、兩終極三項挑戰，各首次成功 25 點。100 點可抽一次，總收入相當於 24 抽，保底後未使用資源保留；完成全部 51 個目標直接補齊本期收藏。

每個獎項 10%。抽到重複形態轉 10 共鳴碎片，100 碎片可指定尚未持有形態；全收集後停止扣款。新角色原裝與夏日裝分開，先得到夏日裝即可出戰，不會同時得到原裝。

編隊卡片會標出持有多套造型、可以換裝的隊員。從角色面板開啟造型，點選任何一套可預覽立繪、攻擊屬性與能力差異；按「裝備」才會套用並儲存，關閉預覽不會換裝。未持有的造型顯示鎖定與取得方式。圖鑑也保留形態選單；有進行中的行動時不能換裝。

每種敵人有固定弱點；玩家攻擊命中對應弱點為 1.5 倍，其他為 1 倍，沒有抗性減傷。角色的普通攻擊、終極及衍生傷害都採用裝備形態屬性；不增加控場時間或盾量。服裝採優點／代價互換，不疊加收藏能力。

## 本地存檔

進度保存在 **目前瀏覽器、目前網址來源的 IndexedDB**。每五秒現實時間及取得技能、波次、暫停、切換速度等關鍵操作保存。戰局只存在本次遊玩階段，不寫入可恢復的戰鬥快照，重開不提供中途續戰。缺少速度偏好的舊存檔自動補上 1×。

每次進入關卡都是獨立新局。離場或重新載入後不恢復本局；角色收藏、已確認編隊、關卡紀錄與偏好設定保留。作戰分頁負責選關，編隊先顯示目前小隊，按「編隊」進入草稿編輯，最後一次確認套用。

技能樹按鈕也可在戰鬥中打開，查看時暫停；關閉後回到原本的戰鬥／暫停狀態。目前的 192 節點、各角色前置與換裝差異、等點數試算見 [分岔技能樹](docs/SKILL_NETWORK.md)；早期版本記錄保留於 [自由技能樹規格](docs/FREE_SKILLS.md)。

- localhost、區網 IP、不同埠或不同瀏覽器是不同存檔；這不是雲端同步。
- 清除瀏覽器網站資料會清除紀錄；私密瀏覽可能只暫時保存。
- 多分頁衝突會提示重新讀取，舊頁不能覆寫新進度。
- 損壞／不相容紀錄會保留並顯示恢復選項，不會自動重置。設定中的重置需要明確確認。
- 瀏覽器拒絕儲存時可明確選擇暫存遊玩；畫面會說明尚未保存。

## 檢查與測試

```sh
npm run typecheck
npm run test:rules
npm run test:simulation
npm run test:e2e
npm run build
```

規則與存檔測試使用 Vitest、fake-indexeddb；主線驗證以初始角色原裝逐 tick 模擬 51 個目標 × 3 組種子，共 153 局，另驗證十種獎池形態最終關及第 7 點存檔恢復。`npm run test:simulation:free` 比較 29 個終極、兩種投入、前三關與十個固定種子（`-- --quick` 使用一組種子）；`npm run test:tree-matchups` 另做 200 個固定敵群探針。`npm run test:simulation:v2` 保留 0.2 版本的 840 局策略。舊 A/B 平衡策略可用 `npm run test:simulation:legacy` 重現。瀏覽器測試使用開發模式的限定測試入口，預設 `npm run test:e2e` 會在 5173 啟動 dev；若 preview 正在執行，可用 `E2E_PORT=5174 npm run test:e2e`，以獨立埠與測試瀏覽器執行。首次需執行 `npx playwright install chromium webkit` 取得測試瀏覽器。測試入口不會出現在正式 build。

`npm run test:performance` 量測桌面純模擬壓力；build 後 `npm run test:assets` 檢查素材清單及容量。`npm run test:production` 保留舊版中途續戰流程的驗證腳本；現行重開規則以 `npm run test:offline` 的正式建置驗證為準。先執行 `npm run build`，再執行 `npm run test:offline:unit` 與 `npm run test:offline`，涵蓋完整下載、斷網重開、永久進度保留及更新安全。

## 程式結構

`src/sim/`：30 Hz、無渲染依賴的確定性戰鬥；`src/data/`：角色、路線、敵人及關卡；`src/storage/`：有序交易與 revision 衝突控制；`src/ui/`：繁體中文操作流程；`src/game/`：Phaser 畫面與原創合成音訊；`public/assets/`：本機美術素材。

這份交付不代表已完成真實手機效能或真人趣味性測試。實際裝置與真人驗證記錄會在工程交付報告中分開列示。
