# 星骸防線：黎明反攻

單人手機直向網頁塔防。近未來地球遭外星入侵，六位成年美少女以改良的外星科技武器展開反攻。自由選擇最多五人出戰，靠局內改造、隊伍分工與隊長技能完成六至八分鐘的防守。

免登入；所有角色與武器路線初始開放。通關只解鎖後續關卡、故事及挑戰，沒有角色永久等級、抽卡、體力或刷資源。

## 本機啟動

需求：Node.js 22.12 以上（實測 22.22.3）及 npm。從本專案資料夾執行：

```sh
npm ci --no-audit --no-fund
npm run build
npm run preview
```

電腦開啟 <http://localhost:5173/>。手機連上同一個 Wi-Fi，再開啟終端輸出的 `Network` 網址；本次開發機實際網卡網址為 <http://192.168.68.110:5173/>，日後可能隨網路改變。主機需保持開機且 preview 仍在執行。

開發時使用 `npm run dev`。dev 與 preview 都固定 **5173** 且拒絕自動換埠，只能同時啟動其中一個；先在原終端按 Ctrl+C，再換另一個命令。不要直接雙擊 `index.html`。`dist/` 是可交付靜態網站，尚未公開部署。

## 操作

1. 選擇關卡並查看敵人情報；在編隊頁加入 1–5 人，指定一名隊長及角色偏好路線。
2. 點擊「開始行動」。武器自動索敵；點擊隊長技能按鈕施放技能，留意敵人的蓄力文字與紅色預警。
3. 升級時戰鬥完全暫停，先選一張改造，再確認。I 級鎖定 A/B 路線，II 級取得後可進化 E；全隊最多三把 E。
4. 第 1、4、7、10、13、16 次改造可指定聚焦角色；已就緒的 E 可切換。每局三次重抽，只更換普通隨機格。
5. 擊敗六分鐘時登場的 Boss 並清除剩餘敵人。八分鐘仍未完成或防線 HP 歸零則失敗。

戰鬥右上角的速度按鈕依序切換 **1× → 2× → 3× → 1×**，選擇會自動記住。敵我攻擊、移動、冷卻、波次與倒數同步加速；選卡與暫停時完全停止。六至八分鐘指有效戰鬥時間，全程 3× 約需兩分至兩分四十秒，另加選卡及暫停時間。

六人具有各自的瞄準、射擊與後座逐格動作，六把武器、12 種 E 與六種隊長技能有不同演出。技能出現約半秒的下方特寫，戰鬥持續進行；3× 下預警保持最高圖層，密集戰鬥會自動減少裝飾特效。

技能按鈕旁的「自動施放」可隨時開關，也可在設定中調整。開啟後，場上有敵人且冷卻完成時會自動使用隊長技能；仍沿用原本索敵、傷害與冷卻。設定保存在目前瀏覽器，初始關閉；暫停、選卡、背景暫停與禁用技能挑戰均不會自動施放。

八種敵人與三隻 Boss 新增待機、六格移動、蓄力和出手動作。3× 下步態有可讀性上限，實際移動與攻擊時序仍同步加速。

桌面可按空白鍵施放技能、Escape 暫停；所有選項也可用鍵盤 Tab 操作。手機切背景或橫放時暫停，返回後需確認繼續。暫停／選卡時間不計入有效戰鬥時間。

## 本地存檔

進度與完整戰局快照保存在 **目前瀏覽器、目前網址來源的 IndexedDB**。每五秒現實時間及改造、重抽、波次、暫停、切換速度等關鍵操作保存。重開頁面可繼續最近成功保存點，包含敵人、護盾、燃燒、彈體、技能冷卻與原候選牌。舊存檔自動補上 1× 速度，不需重置戰局。

- localhost、區網 IP、不同埠或不同瀏覽器是不同存檔；這不是雲端同步。
- 清除瀏覽器網站資料會清除紀錄；私密瀏覽可能只暫時保存。
- 多分頁衝突會提示重新讀取，舊頁不能覆寫新進度。
- 損壞／不相容紀錄會保留並顯示恢復選項，不會自動重置。設定中的重置需要明確確認。
- 瀏覽器拒絕儲存時可明確選擇暫存遊玩；畫面會說明尚未保存。

## 檢查與測試

```sh
npm run typecheck
npm run test:rules
npm run test:simulation
npm run test:e2e
npm run build
```

規則與存檔測試使用 Vitest、fake-indexeddb；完整平衡測試只透過正式命令與逐 tick 模擬，執行三種構築各十個固定種子，並保留路線與技能對照的成功和失敗結果。瀏覽器測試使用開發模式的限定測試入口，請先停止 preview；`npm run test:e2e` 會啟動 dev。首次需執行 `npx playwright install chromium webkit` 取得測試瀏覽器。測試入口不會出現在正式 build。

`npm run test:performance` 量測桌面純模擬壓力；build 後 `npm run test:assets` 檢查素材清單及容量。切換至正式 preview 後，可用 `npm run test:production` 在限制頻寬的 Chromium 中驗證切換 3×、真實等待升級、保存與重載，不使用開發測試入口。

## 程式結構

`src/sim/`：30 Hz、無渲染依賴的確定性戰鬥；`src/data/`：角色、路線、敵人及關卡；`src/storage/`：有序交易與 revision 衝突控制；`src/ui/`：繁體中文操作流程；`src/game/`：Phaser 畫面與原創合成音訊；`public/assets/`：本機美術素材。

這份交付不代表已完成真實手機效能或真人趣味性測試。實際裝置與真人驗證記錄會在工程交付報告中分開列示。
