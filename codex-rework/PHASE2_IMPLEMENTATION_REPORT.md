# 第二階段實作與驗證紀錄

日期：2026-10-07

依 `03-PHASE2_CRISIS_AND_COMMANDER.md` 完成防線危機與指揮官主動戰術。先前全部工作已保存於 `552f55a`；本次 Phase 2 修改保留在工作區，尚未另行提交。

## 實作結果

- 防線受傷後生命值 ≤20%、且仍存活時，每局觸發一次 EMP。Y≥270 的存活敵人擊退 200px、暈眩 60 ticks，打斷蓄力並取消衝刺；本次緊急保底不受首領控場抗性或位移倍率削弱。完全由護盾吸收的攻擊、致命傷不會觸發。
- 全息磁暴牆每波一次，持續 90 ticks；阻止前方敵人跨線，已越過的敵人不會被瞬移。下一波重置次數並移除殘留力場。
- 軌道集束砲在確認座標後冷卻 900 ticks，18 ticks 後對 120px 範圍造成 raw 3000 plasma 傷害、忽略 50% 護甲、對盾倍率 2。沿用正常增傷與弱點結算，但不受隊長外觀形態改寫傷害類型；範圍不受一般區域攻擊 20 名目標上限限制。
- 延遲轟炸使用現有可序列化 `ScheduledHit`，存檔、JSON 還原、暫停、續玩與 action log 皆可保留。波末會等待已呼叫的軌道砲完成後才配點／切波。
- 戰鬥右下方新增兩個戰術按鈕與冷卻／下波充能文字。軌道砲支援觸控與滑鼠選點、方向鍵移動、Enter 確認、Esc／再次點按取消；瞄準取消不消耗冷卻，也不會誤觸集火。暫停時取消瞄準並禁用按鈕；禁止技能挑戰同樣禁用主動戰術。
- HP<30% 顯示全戰鬥畫面邊緣紅光心跳；恢復至30%後移除。新增 EMP 藍環、磁暴牆網格電弧、轟炸預告與金色衝擊波，軌道砲震屏為180ms／0.008。
- 系統減少動態效果偏好會停用紅光呼吸與震屏，保留靜態危機紅框及技能特效。遊戲減少特效選項亦停用技能震屏。
- 歷史內容版本維持原有初始化與被動戰鬥規則，回放雜湊測試不變；目前內容版本缺少新增選填欄位的既有快照仍可讀取。

## 規格適配

1. **力場 Y=400**：本專案 `WORLD.wallY=450`，敵人移動上限也是450；規格的Y=500位於防線後方，無法攔截敵人。因此使用 `BARRIER_Y = WORLD.wallY - 50`，規則與繪圖共用同一常數。
2. 規格以函式閉包描述的延遲排程改用既有資料封包，避免破壞存檔和確定性回放。
3. 範圍相交沿用既有碰撞語義：敵人中心距離≤120加上敵人半徑。
