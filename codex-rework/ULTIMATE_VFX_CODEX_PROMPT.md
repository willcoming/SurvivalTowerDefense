### 🎯 核心實裝目標（打造現代手遊高質感電影級演出）：

#### 1. 優雅融入的角色 CD 能量反饋 (`src/game/ultimate-energy-effects.ts`)
* **充能中 (Progress 0% ~ 99%)**：
  * **科技蓄能條**：位於角色頭像下方（y ≈ 514），尺寸 44px × 3.5px，深色金屬邊框，依照角色元素（熱能橙紅、電漿藍紫、重力青綠）平滑注入，帶有柔和平緩的橫向掃光（Shimmer）。
  * **腳底同心微光（Floor Resonance）**：在角色站立的地面（y ≈ 506），呈現半徑 18px ~ 28px、alpha 0.08 ~ 0.18 的極淡自然漸變光暈，隨進度微幅呼吸，完全不遮擋角色本體。
  * **武器前端微光**：充能達到 75% 以上時，武器前端凝聚微弱微光粒子，體現能量充盈。
* **100% 蓄滿就緒 (Ready to Fire)**：
  * **璀璨金黃充能條**：能量條轉為璀璨高貴的金黃色，並有微光向外擴散溢出。
  * **底座金光呼吸環**：角色腳底浮現精緻的極薄微型光盤，帶有金光呼吸律動（0.4 秒週期）。
  * **絕對不要在角色頭上或身旁生成浮動的小球！**

#### 2. 大招觸發的電影級三段式節奏 (`src/game/scene.ts` & `src/game/ultimate-energy-effects.ts`)
* **瞬間背景微暗 (Focus Dimming, 0 ~ 180ms)**：
  * 終極技發動瞬間，背景戰場與非焦點層微暗 20%（持續 180ms 後平滑淡出），將玩家視覺瞬間聚攏至核心。
* **施法者閃白蓄力 (Caster Flash, 0 ~ 80ms)**：
  * 施法角色身上產生柔和的瞬間閃白光芒，配合 3 幀的受擊頓挫（Hit-stop）。
* **切角高質感大招橫幅 (Ultimate Skill Banner)**：
  * 位於角色欄上方（y ≈ 435），高 22px，半透明科技深藍黑底色、帶切角與微光邊線。
  * 左側顯示屬性標籤（如 `[電漿]`），右側以俐落燙金白字展現技能名稱（如 `雷娜 · 【廣域超導爆震】`、`瑪音 · 【軌道聚焦炎爆】`）。
  * 橫幅從左向右展開滑入，停留 350ms 後向右平滑淡出。

#### 3. 各角色專屬戰場頂級自然光效（徹底淘汰海膽尖刺，全面使用漸變與粒子）
* **⚡ 雷娜（C02）·【廣域超導爆震】**：

  * 目標中心向外快速擴散 2 道同心藍白能量漸變衝擊環（Soft Radial Ring，非線框），受擊中心爆發藍白細密電火花粒子，地面留有電磁餘燼微光。
