## 元素連鎖

| 連鎖 | 觸發與結算 |
| --- | --- |
| 烈焰黑洞 | 帶有效熱能燃燒的敵人受到重力攻擊，將140px範圍內敵人朝命中中心拉近35px，擴散原始燃燒DPS的2倍、持續3秒。首領位移沿用抗性，保留燃燒基準避免重複擴散指數放大。 |
| 超導貫穿 | 電漿／電弧命中留下3秒帶電標記，後續動能命中必定暴擊並忽略100%護甲。沿用現有暴擊倍率：基礎1.5倍，已帶暴擊倍率的傷害不再乘一次。 |
| 電磁引爆 | 有有效重力來源減速／暈眩的敵人受到電漿／電弧命中，附加12%最大生命真傷，首領每次最多1500；繞過護盾與護甲、打斷蓄力。致死仍走正常擊殺、經驗、首領完成與集火解除結算。 |
| 等離子過載 | 熱能燃燒目標有護盾時受到電漿命中，結算前將完整破盾倍率乘2.5，包括既有隊長破盾加成。電弧不觸發此組。 |

每個敵人、每組連鎖獨立冷卻15 ticks（0.5秒）。時鐘以模擬tick計算，暫停時凍結；帶電標記、冷卻及擴散燃燒基準皆可序列化及驗證。歷史內容版本維持既有規則與回放雜湊。

連鎖以500ms亮色標籤與粒子呈現，包括紫橙漸層黑洞文字、收縮螺旋、藍色電火花與金色碎裂。文字物件最多8個且重用；系統／遊戲減少動態效果時保留靜態提示與淡出。

## 手機流派卡片

- 波末配點在寬度小於768px時預設三張卡片：群攻掃蕩流、弱點斬首流、控場時滯流。
- 每張卡片顯示本次將取得的實際角色／技能與總點數。規劃器依技能效果、後續路徑相關性及合法前置選配，並配合目前出戰隊伍與形態。
- 一鍵選配逐項呼叫原有 `buy-node` 指令，不新增繞過規則的解鎖入口。取得後留在配點畫面，可查看成果或開始下一波；沒有可用點數／合法技能時停用按鈕。
- 原有24節點星圖完整保留，可來回切換；桌面預設星圖。下一個波末會重新預設卡片。切換與改變視窗尺寸不消耗點數或清除已取得技能；待選技能存在時，卡片禁止覆寫。
- 短螢幕以卡片內容區內捲動，底部固定保留專家星圖與開始下一波按鈕。

## 規格範例適配

規格中的超導條件同時要求單一封包為電漿／電弧與動能，無法成立；改為先帶電、再動能命中的兩步反應。暴擊、破盾倍率移至傷害結算前。黑洞改用朝中心的向量牽引，而非負數擊退；燃燒依使用者要求採原始DPS的2倍。重力控場以效果元素／來源判斷，防線緊急EMP不視為重力來源。
