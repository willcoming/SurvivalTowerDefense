# Phase 3 修正：星圖回歸與自動戰鬥

日期：2026-10-08

依 `04-PHASE3_COMBAT_SKILLS_AND_RESTORE.md` 實作；本紀錄取代前版 Phase 3 卡片介面的完成狀態。

## 戰鬥操作與被動危機

- 移除 `.commander-tactical-hud`、磁暴牆／軌道砲按鈕及 HUD 狀態更新，移除事件分發、瞄準切換、滑鼠與鍵盤確認轟炸邏輯。
- 刪除 `CommanderEffects`，改為只渲染被動 EMP 的 `CrisisEffects`；不建立手動瞄準或磁暴牆的渲染資源。
- 防線低於 30% 保留心跳紅光；低於 20% 的非致死實際傷害自動觸發一次 EMP，擊退附近怪物 200px 並暈眩 2 秒，一局限一次。20% 整不觸發，測試涵蓋邊界、吸收傷害、致死及暫停。
- 戰場點選／鍵盤集火、暫停、倍速、角色自動攻擊與自動終極技保留。舊指揮官模擬指令及存檔欄位保留供既有紀錄相容，遊戲 UI 不再提供施放入口。

## 星圖恢復

- 波末統一使用 `usesFreeSkills(run) ? deepTreePanel(run, this.vm) : treePanel(run, this.vm)`；不依螢幕寬度攔截。
- 移除卡片狀態、HTML、流派規劃器、切換卡片事件，以及 `src/sim/quick-build.ts`、`src/ui/build-cards.css`。
- 點節點開簡介；「確認配置」逐項扣點；「關閉」或 Escape 取消。保留前置／點數限制、待選狀態、拖曳、縮放、全覽及開始下一波。
- 舊 `phase3-cards.spec.ts` 改為 `phase3-combat-restore.spec.ts`，直接驗證各尺寸星圖與跨尺寸保留彈窗；既有測試助手不再代按卡片切換鈕。

## 四種角色連鎖

既有四組反應與每敵人、每組 15 ticks 冷卻保留：140px 烈焰黑洞聚怪及 2 倍燃燒、帶電後動能必暴擊且無視護甲、重力控場後 12% 最大 HP 真傷（首領上限 1500）及打斷、熱能燃燒後電漿對盾倍率 2.5。

超導貫穿新增真正的次級電弧傷害與目標連線：120px 內最近兩個目標，每道取觸發暴擊封包傷害的 30%，按電弧正常處理盾／甲／擊殺／經驗。規格未指定電弧數量、距離與傷害，採此有界設定；次級電弧不再觸發元素連鎖，避免遞迴爆發，且主目標死亡仍可傳導。

新增紫橙螺旋、藍白鋸齒電光與金色碎盾粒子，過載標籤統一為「等離子過載」。電磁引爆提供 80ms 目標受擊畫格與位置停頓、節流震動；停頓限於呈現，不更動模擬時間。標籤持續 500ms 並上浮淡出，最多重用 8 個文字物件。減少動態效果模式保留靜態提示、關閉受擊停頓與震動。
