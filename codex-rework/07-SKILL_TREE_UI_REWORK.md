# 07. 技能樹與星圖 UI/UX 重構規格 (Skill Tree & Constellation UI Rework)

> **重構目標**：
> 徹底優化波末配點與圖鑑預覽中的「24 節點專家星圖」，解決**「手機視窗兩側切邊」、「置中彈窗遮蔽路線」、「電路板線條生硬」、「節點圖標千篇一律重複」**與**「桌面空間浪費」**等問題，打造現代高質感手遊等級的技能星圖系統。

---

## 🔍 現況問題與痛點深刻診斷

1. **手機視窗（390px）兩側嚴重截斷**：
   - 預設縮放 85% 下，水平橫跨的左右兩側分支（左側群襲增幅、右側獨擊增幅與終極技）被直接裁切在螢幕外，玩家第一眼無法看清整棵星圖的全貌，迷失感重。
   - 右上角的手勢提示文字（`network-gesture-hint`）直接硬生生壓在節點上方，產生嚴重的文字與圖案重疊。
2. **置中彈窗遮蔽星圖，操作疲勞**：
   - 點選任何節點時，中央立即彈出大型深黑遮罩彈窗（`dialog.mobile-detail`），把剛剛選中的節點及前後相連的前置與後續路線全部遮死死。
   - 玩家無法邊看路線邊配點，必須反覆「點開 ➔ 關閉 ➔ 拖曳 ➔ 再點開」，在 24 節點比對時體驗極為割裂。
3. **電路板生硬感與單調灰藍**：
   - 連線為直角折線與虛線，純灰黑背景，缺乏星空深邃感與能量流光。
   - 每個角色的星圖皆為千篇一律的灰藍色，沒有體現瑪音（熱能金紅）、雷娜（電漿淡藍）、米菈（重力深紫）的專屬屬性光彩。
4. **節點圖標千篇一律（全是小劍）**：
   - 絕大部分節點內部都畫同一把小劍（`⚔️`），無法一眼區分攻擊、攻速、暴擊、穿甲或範圍機制。
   - 終極技能節點尺寸與普通節點無異，缺乏作為技能樹終點的「殿堂級儀式感」。
5. **桌面橫式（1440px）空間浪費**：
   - 畫面中央僅有小小的星圖，左右兩側留下巨大且空洞的黑色死區，未利用寬螢幕展示流派詳情與數值連動。

---

## 🎯 核心重構規格

### 1. 互動架構：非遮蔽「底部抽屜 / 側邊面板」取代置中彈窗
* **手機端（寬度 < 1024px）—— 底部抽屜（Bottom Sheet）**：
  * 點擊節點時，**不再彈出覆蓋全屏中央的 Modal 遮罩**！
  * 改為由螢幕底端滑出高度約 **135px ~ 155px** 的半透明科技深藍底抽屜（`bottom-sheet`）。
  * **星圖保持可見**：星圖視角平滑微移，將被選取的節點聚焦於螢幕中上方，節點外圈高亮聚光（Focus Ring）。
  * 抽屜內容包含：
    * 左側：**44px 專屬彩色圖標** + 狀態標籤（【已取得】/【可配置】/【待確認】/【前置未達成】）。
    * 中間：**技能名稱**、**前置路線標籤**、**一針見血的效果描述**。
    * 右側或底列：**【確認配置】按鈕**（綠/金主色，點數不足時禁用）與微型【關閉】按鈕。
  * 玩家可以**一邊凝視星圖上的前後脈絡，一邊一鍵配置**，無需反覆開關視窗。
* **桌面端（寬度 ≥ 1024px）—— 雙欄大版面（Split View）**：
  * 左側 70%：高解析星圖全景，支援平滑縮放與拖曳。
  * 右側 30%：常駐側邊資訊面板（寬 320px ~ 360px），顯示當前隊員立繪、目前武器數值、選中節點的詳細說明與全隊連鎖反應預覽。

---

### 2. 視窗適配與邊界最佳化：防切邊與清潔排版
* **自動全覽置中（Auto-Fit Viewport）**：
  * 在 `src/ui/skill-map-controls.ts` 中優化相機初始化邏輯：
    * 當打開波末配點時，自動計算包含「入口 ➔ 當前已取得節點 ➔ 可配置節點」的最佳 Bounding Box。
    * 手機端初始縮放比例與邊距自動調整，確保水平所有分支（24 節點的左右端）完整落在視窗邊界內，不被左右截斷。
* **清理手勢提示重疊**：
  * 移除 `src/ui/skill-map-controls.ts` 內浮動在畫布右上方的 `.network-gesture-hint`（「虛線：跨分支前置 · 拖曳／縮放」）。
  * 將手勢提示改為底端工具列左側的極淡小標註，或移至工具列的 `?` 圖示中，保證畫布 100% 乾淨無遮擋。

---

### 3. 終極技能節點：殿堂級終極地位（Ultimate Node Prestige）
* 終極技能是整棵 24 節點專家星圖的最高追求，視覺必須極具存在感：
  * **尺寸擴大 1.35 倍**：外徑提升至 **58px ~ 62px**（普通節點為 44px）。
  * **高貴雙層金環**：雙層細膩金色外圈（帶有緩慢旋轉的 0.15 偏角流光），內部填充深邃金黑漸變。
  * **專屬大招紋章**：根據角色終極技能設計專屬燙金紋章（而非普通幾何符號）。
  * **可解鎖時金芒脈衝**：當前置滿足且點數足夠時，終極節點散發向外擴散的金色微粒光波，對玩家形成強烈的指引誘惑。

---

### 4. 節點圖標分類體系（多元專業 Icon，告別千篇一律小劍）
重構 `src/ui/skill-constellation.ts` 的 `skillEmblem(node)` 函式，依據節點的屬性加成（`node.mods`）呈現清晰分類的精緻 SVG 圖標：
1. **攻擊增傷（Damage / Power）**：鋒利光刃 / 貫穿劍尖（Blade）。
2. **攻速散熱（Haste / Cooling）**：疾風閃電 / 散熱風道（Lightning / Vent）。
3. **穿甲破防（Armor Pierce）**：穿透箭鏃 / 破碎菱形（Piercing Arrow）。
4. **暴擊弱點（Crit / Weakness）**：精準十字準心 / 璀璨四芒星（Scope / Star）。
5. **範圍引力（Radius / Pull）**：同心擴散光環 / 旋轉漩渦（Vortex / Ripple）。
6. **防禦護甲（Shield / Armor）**：科技能量力場盾（Hex Shield）。
7. **彈道分流 / 飛彈（Missile / Split）**：散射多重箭頭 / 雙子導彈（Spread / Missiles）。

---

### 5. 節點四種狀態與光之脈絡（Energy Veins）
* **節點狀態（Node States）**：
  * **`owned`（已取得）**：實心角色屬性光（或金黃色）底座 + 精緻打勾標記，向外引出的連線保持持續發光。
  * **`available`（可配置）**：醒目的呼吸邊框（0.6s 週期淡光律動）+ 明亮箭頭，一眼可見「當前能點這裡」。
  * **`pending`（待確認）**：金色跑馬邊框 + 「+1」點數浮動標記。
  * **`locked`（未達成前置）**：半透明金屬灰底，點擊時在底部抽屜以醒目琥珀色標示「缺少的前置技能名稱」。
* **光之脈絡連線**：
  * 已解鎖的路徑線條加粗至 2.5px，帶有微弱的能量流動粒子（Flow Animation）。
  * 跨分支前置虛線採用柔和點狀光，不干擾主幹路線。

---

### 6. 流派分支標籤（Archetype Badges）
* 在 3~4 條主幹分支的起點或頂部，標註清晰的戰術流派徽章：
  * 例如瑪音：`【高頻速射流】`、`【穿甲貫穿流】`、`【餘熱爆轟流】`。
  * 例如雷娜：`【廣域感電流】`、`【超導穿刺流】`、`【電磁過載流】`。
* 點擊流派徽章或切換下拉選單時，整條流派路線的所有節點與連線**同步呼吸高亮**，引導玩家快速理解流派走向。
