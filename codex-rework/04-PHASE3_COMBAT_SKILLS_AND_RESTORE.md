# 04. 第三階段實施規格：回歸星圖點選、移除手動技能、深化角色技能特效 (Phase 3)

> **使用者的核心回饋**：
> 1. **不要手動主動技能**：移除戰鬥右下角的「全息磁暴牆」與「軌道砲」手動按鈕，回歸純自動塔防與自動施法。
> 2. **恢復之前的星圖點選版本**：移除三張卡片的 `buildCardsDialog`，恢復原本 2026-10-01 驗證通過的「24 節點技能星圖單項點選彈窗（`deepTreePanel`）」。
> 3. **技能表現由角色的技能親自做出效果**：戰鬥的刺激感與動腦策略，完全交給角色自身普通攻擊、終極技與屬性碰撞在戰場上打出的「雙元素連鎖反應」與震撼視覺打擊！

## 任務 3：角色技能的戰場特效與雙元素連鎖反應 (Elemental Synergy)

戰鬥的刺激感與動腦策略，完全交給**角色自身武器與終極技能在戰場上的化學反應**！玩家透過隊伍編成（熱能、電漿、重力、物理動能角色搭配）在戰場上打出華麗的自動連鎖。

### 3.1 四組角色技能連鎖反應 (`src/sim/combat.ts`)
在 `hitEnemy(s: RunState, e: Enemy, p: DamagePacket)` 命中結算處，由角色攻擊自動引發：

1. 🌀 **【烈焰黑洞】 (熱能燃燒 + 重力牽引)**：
   * **觸發**：目標帶有熱能燃燒 (burn) 且受到重力 (gravity) 攻擊或力場影響。
   * **效果**：以目標為中心引發吸力漩渦，將半徑 140px 內怪物向中心拉扯，並將當前燃燒傷害以 2 倍擴散至漩渦內全體敵人！
   * **事件**：`emit(s, { kind: 'combo_vortex', x: e.x, y: e.y })`

2. ⚡ **【超導貫穿】 (電漿/電弧 + 物理動能)**：
   * **觸發**：電漿/電弧命中使目標帶電（ionized），後續物理動能 (kinetic) 子彈命中時觸發。
   * **效果**：該發物理子彈 100% 暴擊、100% 無視護甲，並在目標處炸出藍白電光，向周圍跳躍次級電弧！
   * **事件**：`emit(s, { kind: 'combo_superconduct', x: e.x, y: e.y })`

3. 💥 **【電磁引爆】 (重力減速/暈眩 + 電漿/電弧)**：
   * **觸發**：目標帶有重力來源的減速 (slow) 或暈眩 (stun)，受到電漿/電弧直擊。
   * **效果**：強制打斷怪物蓄力，造成目標最大生命值 12% 真實傷害（首領上限 1500），電光爆震！
   * **事件**：`emit(s, { kind: 'combo_emp', x: e.x, y: e.y, value: trueDamage })`

4. 🛡️ **【等離子過載】 (熱能燃燒 + 電漿直擊)**：
   * **觸發**：帶有熱能燃燒的目標擁有護盾時，受到電漿直擊。
   * **效果**：護盾共振過載碎裂，對盾傷害提升至 2.5 倍！
   * **事件**：`emit(s, { kind: 'combo_overload', x: e.x, y: e.y })`

* **防刷機制**：同一敵人 0.5s（15 ticks）內不重複觸發同一連鎖。

### 3.2 視覺打擊感升級 (`src/game/scene.ts` & `src/game/combo-effects.ts`)
* 收到連鎖事件時，在戰場上演出炫麗特效：
  * **烈焰黑洞**：向中心旋轉的暗紫烈焰螺旋環與聚怪粒子。
  * **超導貫穿**：藍白強光炸裂與向外迸射的電弧火花。
  * **電磁引爆**：青藍色震盪光環、受擊頓挫（Hit-stop）與電光爆震。
  * **等離子過載**：金色護盾碎裂粒子。
  * **連鎖字樣浮動標籤**：目標頭頂彈出極富質感的亮色標籤（如 `【烈焰黑洞】`、`【超導貫穿】`），持續 500ms 伴隨受擊頓挫上浮消散。
