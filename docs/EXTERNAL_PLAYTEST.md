# 工程版交付後的真機與真人測試

**狀態：尚未執行。** 本文件提供可直接使用的測試腳本與空白紀錄。AI 的桌面瀏覽器／模擬資料不能填進本表冒充真機或真人結果。負責人為使用者或其指定測試者；完整工程可玩版可用後執行，不要求先購買裝置或服務。

## X01：實際手機

至少一台實際 iPhone 使用 Safari、一台中階 Android 使用 Chrome。手機與開發電腦連相同Wi-Fi，依README啟動preview並開啟實際區網網址。localhost只指向目前裝置，請使用電腦的區網IP；每台手機進度独立，清除網站資料或換網址不會自動同步。

先完整玩一局，再檢查下列中斷場景。一次只改一個因素，留下時間與重現步驟：

1. 在編隊頁確認六人可選、滿編五人、可點隊長與兩條偏好路線。所有關鍵文字无需hover。
2. 戰鬥時查看五人、敵人蓄力、HP及唯一隊長技能，確認瀏覽器上／下工具列沒有擋住技能。
3. 升級時切換聚焦、重抽、先選卡再套用；長說明能捲動，套用按鈕可操作。
4. 戰鬥中切到其他App約10秒，再返回，應先維持暫停；繼續後沒有補算10秒傷害。
5. 在升級畫面鎖屏再解鎖；牌面、重抽次數及尚未套用的選擇不應自行改變。
6. 橫向手機應暫停並提示轉回；回直向仍由玩家確認繼續，不能跳過正在選牌。
7. 刷新戰鬥頁，從「繼續行動」恢復；可能回到最近成功保存點，正常最多約5秒，不應整波重來或重置技能。
8. 靜音與低特效各測一次；危險仍可由文字／圖示辨認，規則不變。完成一局後確認下關解鎖。
9. 若有瀏覽器開發工具或遠端診斷設備，錄製最密集60秒的frame time，記錄P95。没有工具就保留未量測，不能把「感觉順」填為60FPS。

## X02：五位未讀規格的玩家

測試者不先解釋哪套隊伍比較強，也不告知三個驗收流派。允許玩家閱讀遊戲內的情報、圖鑑和教學。五位参与者可以依序使用各自的空白瀏覽器進度；不收集真實姓名，代號P1–P5即可。

開場只說：**「請組成一支隊伍，守住這個據點。你可以隨時讀畫面上的說明；選擇由你決定。」**

觀察第一次失敗後的自然動作，不立刻給攻略。若玩家在有限時間內没有失敗，保留「尚無首次失敗資料」，不要製造或代填失败。接著依序問：

1. 「你認為這次哪些敵人造成最多壓力？」
2. 「如果再玩同一場，你想改哪個角色、武器路線或技能時機？為什麼？」
3. 「你覺得必須先升等、刷材料或多打幾局累積戰力，才有機會過嗎？哪個畫面讓你這樣想？」
4. 讓玩家實際調整並重試，記錄他做了什麼，與他说的理由是否一致。

不要問「是不是很好玩」等暗示答案的問題。可加問「你會不會主動再換另一個搭配？最想改哪一點？」取得方向，但不把這個回答當作遊戲勝率。

## 結果回收

將填好的表格、遊戲版本及重現步驟交回專案。若发现操作阻塞、錯誤保存或明顯不可辨識的預警，優先修正並重跑受影響的自動化案例；若只是流派偏好不同，先保留玩家原話與構築，不直接提高永久戰力或增加刷取系統。
