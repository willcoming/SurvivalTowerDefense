## 文件維護

修改節點後，以 `npx tsx scripts/export-free-skill-spec.ts` 更新節點表。研究報告由 `npx tsx scripts/report-free-skill-validation.ts` 讀取已收集的驗證資料產生；生成文件本身不代表重新測試。完整重現方式見測試策略。

0.4 測試資料位於 artifacts/validation/0.4.0-dev.1；既有報告保留其版本標示。本次沒有新增真機或真人測試結果。原始企劃、A/B 測試政策及各次動畫更新保留為歷史，避免將舊版三選一或 18 次升級混入目前規格。
