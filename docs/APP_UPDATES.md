# 遊戲版本與強制更新

主畫面與設定顯示內容版本、七碼修訂碼，以及固定的建置日期時間（台灣時間，精確到秒）。`version.json` 的 `builtAt` 使用 UTC ISO 格式；它與畫面資料來自同一次建置，並非玩家開啟頁面的時間。戰鬥內容版本不因介面更新而變更。

設定中的「強制更新」會重新檢查伺服器版本、完成離線快照的完整性驗證、等待存檔佇列，再啟用新版並重新載入。即使已是最新版，也會檢查／修復快取後重新載入。此功能不清除 IndexedDB、收藏或設定。斷線、下載失敗或存檔未完成時保留目前頁面，並提供可重試的訊息。

戰局中的按鈕停用；若下載期間開始戰鬥，也會在切換前阻擋更新。其他開啟中的遊戲分頁保留原素材快照，直到自行重新載入；快照與分頁的對應存入快取，背景程序重新啟動後仍有效。後續啟用版本時會清理不再需要的舊快取。未點擊按鈕的自動更新仍等待所有舊遊戲分頁關閉。

驗證：`npm run test:offline:unit`；正式建置後執行 `npm run test:offline`，涵蓋 Chromium／WebKit、320／768／1024／1440px、日期時間一致性、雙分頁更新與舊戰局素材、離線失敗、最新版重開、存檔保留及鍵盤操作。

第一次從沒有更新按鈕的舊版升級，需先關閉所有遊戲分頁，再重新開啟。
