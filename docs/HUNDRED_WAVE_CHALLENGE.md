# 百波挑戰

作戰中心的「百波挑戰」獨立開放，使用目前已擁有的編隊、形態及指揮官技能。

- 固定 100 波，波次間隔 20 秒，波內分組間隔 2 秒。
- 每 10 波增加敵人數量、生命與速度，逐步引入護盾、重甲、修復與精英。
- 第 100 波同時登場 B03 首領；不另加第 101 波或首領入口護衛。
- 2,300 隻常規敵人，總計 1,800 經驗、最多 60 點本局技能；每名角色最多 1 個終極。
- 不限時。清完所有波次、首領與殘敵後通關；防線歸零則失敗。
- 完成波數必須是整波已部署、場上沒有該波或更早的存活敵人；第 100 波還必須擊破首領。
- 紀錄依完成波數、擊殺數、達成時防線耐久依序比較，保留最佳表現。戰鬥存檔時同步保存最高紀錄，離開後不保留本局。
- 本機 IndexedDB 保存，重新整理與重新開啟同瀏覽器保留；換裝置或清除網站資料不會同步。
- 此模式不計入主線解鎖、首通招募獎勵或指揮官經驗。

`RunConfig.mode = 'hundred'` 獨立選用挑戰排程與平衡；`stageId = 'S03'` 僅重用背景、敵人與首領資源。未設定 mode 的既有戰役與舊存檔維持原本規則。
