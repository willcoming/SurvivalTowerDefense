# 波末配點與關卡波數

本機版本：`0.6.0-dev.3`；關卡配置 `5`；波次流程 `1`。尚未發布線上版本。

## 玩法

所有主線、支線、難度、限制挑戰和百波挑戰採用「本波清除 → 集中配點 → 下一波」。波中每 60 經驗取得 2 點，只累積不暫停。波末一次開放所有未用點數，可跨角色選擇、部分使用或保留全部。確認後立即推進下一波；沒有可購買技能時自動推進。

配點標示「已用 X / 本關 Y 點」：X 為已消耗點數，Y 為本關可取得的總預算，並非現在可用的數量。右側顯示目前可用點數、暫選數量及確認後保留數量。暫選尚未生效；「保留全部點數並繼續」會取消本次暫選。本局不能洗點，未用點數不帶到下一場。

本波敵人必須全部部署、清除，包括召喚物；敵方彈體及延遲傷害也必須結束。配點期間戰鬥時間、敵我攻擊、冷卻和出怪全部停止，切背景與手動暫停仍獨立生效。手動在波中打開技能樹只供查看。

一般關卡完成所有常規波次和配點後迎戰首領；百波挑戰在第 100 波迎戰首領。保留 1.5 秒首領演出和護衛相對出場節奏。最終清場直接結算，不要求花完點數。首領戰最後取得的點數仍記入取得總額，但不再開配點畫面。

一般關卡首領戰另計。同關卡各難度與限制挑戰採用相同波數及預算，但沿用各自編隊與難度。系統只設至少 10 波，不設通用上限；百波挑戰的 100 波是該模式自己的通關目標。

短關卡以 `新波數 / 舊波數` 比例增加常規敵人總數（四捨五入）與技能點（四捨五入至偶數）。總經驗為技能點 × 30，扣除維持原值的護衛經驗後分配到常規波次。沿用原敵種、權重、整備波和編隊產生規則，以最大餘數法分配整數餘額。不調整敵人生命、傷害或首領倍率。

## 狀態與版本

- 新戰局使用 `waveFlow: { version: 1, wave, startedAt, phase }`，`phase` 為 `combat` 或 `allocation`。
- 新版 `spawnPlan.at` 表示相對本波起點的 tick，依波數及時間排序；只部署目前波次。
- 新版配點的 `pointTarget` 等於全部已取得點數，`choice` 為已完成波數。`confirm-node` 接受合法的部分選擇或空清單，單次確認只推進一波。
- 舊內容及關卡版本保留絕對時間出怪和升級配點；既有快照的生成、還原與舊版摘要測試保留。永久存檔格式不變，正常遊玩仍不保存可恢復的中途戰局。
- 波數、敵情及首領提示改由波次狀態取得，舊規則的首領絕對時間仍只用於舊戰局。

## 驗證

```sh
npm run typecheck
npm test
E2E_PORT=5174 npm run test:wave-flow:e2e
npm run test:wave-flow:simulation
npm run build
```

規則測試涵蓋全部 66 個一般關卡／模式組合、百波挑戰、128 波測試關卡、配點累積與保留、延遲出怪／召喚／敵方攻擊、暫停、終局結算及快照驗證。瀏覽器測試涵蓋 Chromium／WebKit、320／768／1024／1440px、390px 觸控模擬（非實機）、鍵盤操作、1×／2×／3×、背景暫停及跨角色暫選終極名額。完整結果見[驗證紀錄](../artifacts/validation/wave-flow/README.md)。

[固定種子模擬結果](../artifacts/validation/wave-flow/simulation.md) 記錄舊／新版耗時、結果、到達波數與取得／使用點數。66 個一般模式和百波挑戰均未遇到流程逾時；66 個一般模式中此固定隊伍及配點策略通關 4 個，其餘防線失守，百波挑戰也以失守結束。這是流程與成長比較，不代表全關卡平衡已驗收；本次依約保留敵人戰鬥倍率，未據此額外降低難度。
