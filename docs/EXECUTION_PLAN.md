# AI 開發執行計劃

**0.3.0-dev.1 · 2026-09-05 更新**

本次自由技能樹的規則、流程、存檔、畫面、自動化與可玩版交付已完成。以下記錄實際完成順序及剩餘驗證工作，取代「尚未開工」的初始計劃；原 P01–P31 任務與依賴保存在 [歷史執行計劃](history/EXECUTION_PLAN_INITIAL.md)。

## 1. 交付原則

AI 先完成可在本機與同 Wi-Fi 試玩的工程版，並提供可重現測試與原始證據。核心範圍依 [MVP 規格](MVP_SPEC.md)及[自由技能樹規格](FREE_SKILLS.md)：六人選 1–5 人、14 條不對稱樹、共用技能、XP 配點、隊長初始冷卻與本地存檔。

不以永久戰力、付費解法或刷資源修補通關問題。數值變更需有相同預算與配對種子證據；測試失敗保留，修正後新增對應結果。涉及實際手機及真人的結論須由真實測量產生。

## 3. 剩餘工作與順序

| 工作 | 狀態／負責方式 | 執行內容與完成條件 |
| --- | --- | --- |
| X01 真機檢查 | 待執行；使用者或指定測試者操作實際裝置 | iPhone Safari、中階 Android Chrome；完整局、動態工具列、樹捲動／確認區、3× 預警、背景與半途配點恢復；記錄裝置與量測工具 |
| X02 五位真人試玩 | 待執行；使用者或指定測試者主持 | 不預先教構築；觀察選點理解、選擇時間、反制理由及重試，依 [試玩表](EXTERNAL_PLAYTEST.md) 留原話與實際行為 |
| X03 平衡與操作修訂 | 待 X01／X02 的具體觀察，或新的可重現問題 | 若阻塞、存檔錯誤或預警不可辨識，先修正；若某樹缺乏選擇價值，以同投入、控制隊友的對照檢查再調整 |
| X04 外部分享部署 | 尚未執行 | 本機工程交付不依賴公開部署；另有部署需求時再確認目的地、固定來源網址與驗證方式 |
| X05 裝備掉落提案 | 延後 | 技能樹平衡驗收後另提玩法，維持不靠永久累積戰力過關 |

1,500 場代表性構築全勝不等於完成 X02 或全面平衡，也不據此強制每條樹節點總數相同。後續實驗先記錄假說、樣本與判準，再收集新資料，不能刪除未成立對照。

## 4. 重現與維護

目前命令已實作，完整用途見 [測試策略](TEST_POLICIES.md)。針對受影響範圍檢查後，再做所需交付回歸；文件或低影響文字調整不必重跑 1,500 場。

```sh
npm run typecheck
npm run test:rules
npm run test:simulation
npm run test:tree-matchups
E2E_PORT=5174 npm run test:e2e
npm run build
npm run test:assets
```

正式版驗證需先啟動 `npm run preview`，再由另一終端執行 `npm run test:production`。預設 dev／preview 使用 5173；既有 preview 運行時，E2E 使用 5174，不需中斷玩家戰局。驗證輸出可透過 `VALIDATION_OUTPUT_DIR` 分開保存，避免覆寫交付證據。

來源／資料變更後，舊報告保留其原版本和雜湊；不要只重新生成 Markdown 就標記新版已通過。節點表和研究報告的生成工具見 [文件總覽](README.md)。本輪文件更新沿用已收集的 0.3 證據，不修改數值或測試結論。
