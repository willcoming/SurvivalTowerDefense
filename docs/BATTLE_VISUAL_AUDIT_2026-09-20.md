# 戰鬥畫面與技能增加檢查（2026-09-20）

檢查目前工作目錄原始碼、實際瀏覽器畫面與模擬事件。既有工作目錄已有大量未提交修改，本次只調整特效保留與無人機編隊顯示，未改傷害規則。

## 鎖定框以外的線條

| 類型 | 來源 | 出現條件／判斷 |
| --- | --- | --- |
| 防線水平分隔線 | `src/game/scene.ts` | 固定在戰場座標 y=450，不隨技能增加 |
| 射程弧線 | `src/game/range-overlay.ts` | 選取角色射程時才顯示；射程技能會改變弧線位置 |
| Boss／敵人蓄力圈、進度弧、落點橢圓 | `src/game/scene.ts` | 真正蓄力時出現，搭配淡色攻擊區域 |
| Boss 攻擊斜線 | `src/game/boss-assault.ts` | 實際防線受擊事件觸發，約 100ms 內消失；不是玩家武器彈道 |
| Boss 入場橢圓、橫線 | `src/game/boss-entrance.ts` | 入場演出期間 |
| 打斷圓圈與短十字線 | `src/game/effects.ts` | 真正 interrupt 事件，短暫提示 |
| 場景內固定輪廓 | 關卡背景貼圖 | 截圖可見防線後方固定方形輪廓，與技能升級無關 |

一般攻擊、電弧與狙擊使用有限尺寸的貼圖彈體／命中特效；引力場與火區使用貼圖及低透明底色。舊 `src/game/skill-effects.ts` 仍含大量線段，但目前 `BattleScene` 未匯入或呼叫 `drawSkill`，不是本次畫面的線條來源。此次未任意移除具有戰術用途的線條。

## 已修正

1. **連鎖技能增加後畫面遺漏部分攻擊。** `capEffects` 原本每角色僅保留 6 個主攻擊提示，升級 C02 的一次攻擊可產生超過 6 個提示。提高至 12，涵蓋夏日型態完整電弧與磁爆組合，仍保留總量控制。新增完整模式／精簡模式回歸測試。
2. **五機編隊在右側出界。** C06 原本從角色掛載點單向向右排列，最右第五架中心可超過戰場寬度 390。改成置中排列並限制邊界，射擊提示也使用相同編隊座標。新增左右邊界與五架可見的回歸測試。

## 技能增加後的實測變化

使用固定高血量敵人與測試用技能點，透過實際 `buy-node` 指令購買合法路線，再呼叫真實武器邏輯比較升級前後。這是隔離顯示測試，不是完整自然遊玩或所有技能組合窮舉。

| 角色 | 驗證路線與變化 |
| --- | --- |
| C01 | 多重掃射：同次攻擊子彈由 1 顆增加為 4 顆 |
| C02 | 無限迴路與跳躍分支：電弧由 1 段增加為 8 段，加上首發共 9 個提示全部保留 |
| C03 | 長線貫穿：直接命中與末端震波的 hit 事件由 2 增加為 9 |
| C04 | 吸積核心：攻擊後引力場由 0 增加為 1，可見區域貼圖 |
| C05 | 燃燒封鎖：砲彈新增 fire 資料；本隔離測試檢查發射時的火區生成參數，未把它誤算為已落地火區 |
| C06 | 蜂群分支與女王蜂巢：攻擊目標由 1 增加為 5，五架均完整位於畫面內 |
| C07 | 潮線封鎖：地雷爆炸半徑由 58 增為 72.5，部署仍為地雷貼圖 |
| C08 | 赤曜彈幕：子彈新增貫穿次數，仍使用實體彈體貼圖 |
