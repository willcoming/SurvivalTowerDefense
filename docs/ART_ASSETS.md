# 美術素材交付與檢查記錄

本頁保留 art-v1 基準。後續新增六張逐格動作表、36 格姿勢及新的技能演出，見 [動畫更新](ANIMATION_UPDATE.md)。

日期：2026-09-04 · 素材版本：art-v1 · 對應任務：P08、P22

本地已交付 **45 個圖像素材，共 4,177,768 bytes（3.984 MiB）**。其中 26 張為 imagegen built-in 實際生成的角色、外星敵人與場景，6 張武器圖示從同一角色立繪裁切，12 張進化圖示與 1 張共用特效圖集為原創 SVG 圖形轉 WebP。

**runtime 素材已凍結。** 本文件描述素材內容與實際接入方式；遊戲規則、效能與流程是否通過，另以整合驗收報告為準。

## 檔案與追溯

- 執行時資產：`public/assets/`，只有最佳化素材、`manifest.json` 及特效格位 JSON。
- [資產清單](../public/assets/manifest.json)：逐項列出 `assetId`、URL、尺寸、bytes、SHA-256、原始檔、載入組、背景模式及檢查狀態。
- 生成原圖：`artifacts/art-sources/<assetId>.png`，保留生成輸出的原始 PNG，未覆蓋原始輸出。
- [完整生成 prompt 集](../artifacts/art-sources/generation-prompts.json)：記錄所有 26 張採用生成圖的最終 prompt 與工具來源。
- 原創圖示來源：`artifacts/art-sources/icons/*.svg`。
- 檢查報告：[asset-audit.json](../artifacts/art-sources/inspection/asset-audit.json)。
- 重建與 QA 工具置於 `artifacts/art-sources/`，不隨 production 網頁一起提供。這些腳本使用目前工作站已有的 Sharp，不新增遊戲依賴；正常 `npm run build` 不需重新生成圖片。

本次使用 imagegen built-in，沒有使用 CLI/API fallback 或下載其他作品。生成描述使用原創近未來地球防衛世界觀，六位角色皆為成年女性；所有正式 UI 文字由網頁程式提供，圖片不承載操作文字。

## 共用特效的實際接入範圍

`/assets/effects/common.webp` 是 512 × 384 的真 alpha 圖集，`common.json` 記錄 12 個 128 × 128 格位：光點、電弧、衝擊環、火區、重力場、護盾、命中、死亡碎片、脈衝彈、長光束、曝露準星、危險警告。

**圖集目前交付為素材備件，沒有被戰鬥場景載入。** 現有 `src/game/scene.ts` 使用 Phaser Graphics 繪製規則事件驅動的光束、連鎖、爆炸、火區、引力場、護盾、命中、死亡及警告。素材存在不等於已接入；本項不把備件圖集的十二格當成十二個已啟用的新效果。

## 背景鍵色與壓縮

生成工具最初兩次要求透明背景，仍回傳帶棋盤格的 RGB 圖。因此沒有把棋盤格版本作為正式素材，也沒有宣稱 sprite 源檔含 alpha。正式戰鬥角色與敵人以純洋紅背景重新生成，在 [manifest](../public/assets/manifest.json) 明列 `backgroundMode: chroma-key-magenta`。

`src/game/chroma.ts` 於圖片載入時將 **R > 195、B > 195、G < 85** 的像素變為透明，再將處理後的紋理交給 Phaser；來源 WebP 保持原樣。生成 prompt 刻意排除角色身上的洋紅色，以保護髮色、衣裝及光效。

角色立繪與場景以 WebP quality 84 輸出；武器裁切使用 quality 90；鍵色 sprite、向量進化圖示與 FX 使用 lossless WebP，避免有損壓縮破壞單色背景及透明邊緣。原始大圖與生成工具資料未放進 `public/`。
