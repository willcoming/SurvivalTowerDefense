適用於新角色、原裝與主題變裝。真人照片只提供髮型、服裝輪廓與配件參考，不改變遊戲的既有美術風格。

## 必須一致

1. 臉部使用動漫眼睛、簡化鼻口與清楚線稿；維持角色設定中的成人年齡，不用真人五官的寫實塑形。
2. 皮膚與衣料以乾淨、有限層次的賽璐璐陰影為主，避免照片皮膚、毛孔、立體寫實唇形、過度柔焦或 3D 渲染質感。
3. 頭髮以清楚分束及圖形化高光呈現；服裝的金屬、羽飾、流蘇也使用同一套線稿與陰影語言。
4. 變裝保留同一角色的臉部設計、髮色、髮型與比例；服裝、姿勢、表情和武器持握方式依主題設計，不能把「角色一致」理解成「姿勢相同」。
5. 參考照片／概念稿與既有畫風衝突時，以現有 C01／C02 遊戲立繪為準。不能只在提示詞寫 anime，卻交付半寫實圖。

## 本次兩位新角色

- 汐音 C07：淺金長直髮。原裝為銀白羽飾短上衣、黑短褲及銀色鏈飾；夏日裝為淺青短上衣、白短褲及涼鞋。地雷與發射器識別保留。

- 不使用潛水服、蛙鏡、蛙鞋、氧氣瓶或其他潛水裝備。

## 每個主題都要有獨立姿勢

- 同角色不同主題至少改變兩項：身體朝向／重心、手臂動作、腿部站姿、武器角度；只換衣服、換色、鏡像、旋轉或裁切同一姿勢不算新姿勢。
- 原裝著重角色職能與備戰感；夏日裝以放鬆、迎風或操作夏日裝備的動作表達主題，不能只靠背景辨識。
- 汐音：原裝維持正面備戰、發射器下垂；夏日改側身踏步、抬手托起一枚浮標地雷，另兩枚仍在腰鏈。
- 熾夏：原裝維持雙手橫持旋轉砲的穩定站姿；夏日改側步迎風、膝部微彎，雙手將旋轉砲斜向下提持，髮梢與罩衫呈現風向。
- 生成提示詞鎖定臉部、髮型、成人比例、服裝及畫風，但明確要求重新設計動作；不得在跨主題提示詞中要求 preserve pose／保持原姿勢。
- 驗收時同角色原裝與變裝並排看整體輪廓，再確認手指、武器承重、雙腳落點及縮小後的可讀性。每個主題保留獨立素材路徑，不能在前端用 CSS 鏡像代替重繪。

## 匯出與驗收

生成由內建 imagegen 完成；縮放與 WebP 壓縮使用既有打包工具，不以程式重畫人物。全身立繪使用 2:3 畫幅，正式檔案為 512×768 WebP；現有遊戲以純洋紅背景作 runtime chroma 去背，頭髮、雙腳和武器不得裁出畫面。

先將新圖與 C01／C02 並看檢查畫風，再檢查同角色原裝／夏日裝的一致性；最後確認招募卡、編隊頭像、戰鬥角色及隊長演出。新素材使用版本檔名，歷史來源保留但不當作目前畫風標準。
