# 全關卡難度重整

2026-09-13。涵蓋主線 S01–S12、支線 X01–X03 的簡單／困難，以及主線 36 項限制挑戰。

## 遊玩上的變化

- 每關安排自己的威脅順序：快攻、重裝、護盾、砲手、修復、精英及混合敵群，穿插補給間隙。波次名稱與應對提示可在戰前情報及配點時查看。
- 每波的進場間距依編成調整，威脅會集中抵達；困難模式以特殊兵替換部分基礎兵。沒有增加怪物總數或技能經驗。
- 首領登場仍帶入 32 隻零經驗援軍，但會混入關卡既有的特殊兵。三種首領分別調整耐久、傷害與出招間距；完整蓄力預警保留 2／3 秒。
- 策略以局內技能投入順序為主，隊長時機為輔。三套測試隊伍全用初始角色與原裝；五人陣容固定，配點可因敵情調整，四人挑戰可選擇不同的退場隊員。
- 各關既有波數、敵人數、35 秒波次週期、技能點、經驗分配、首領登場與截止時間，以及獎勵與永久進度都維持原值。

簡單模式以零永久升級測試；困難模式只使用前置簡單關與本關簡單首通自然取得的指揮官經驗。限制挑戰額外計入解鎖所需的本關困難通關經驗。測試不依賴招募、夏日形態、刷關或修改戰鬥血量。

## 資料與相容性

`src/data/encounters.ts` 定義 9 種編成及 15 關的逐波安排。`stageProfile(id, difficulty)` 將編成權重投影為關卡允許的敵人種類，保持每波原有敵人數與經驗；`operationProfile(run)` 為模擬與戰鬥情報共用入口。

新戰局記錄 `balanceVersion: 1`。舊戰局缺少此欄位時，沿用舊編成、隨機事件、難度倍率及首領規則；`restoreRun` 不會將舊戰局偷偷升級。這是模擬快照與歷史重播的相容性措施，遊戲既有的「重開結束本局」行為保持不變。

## 驗證方式

```sh
npm run test:difficulty
npm run test:rules
npm run build
E2E_PORT=5174 VALIDATION_OUTPUT_DIR=artifacts/difficulty/browser npx playwright test tests/e2e/progression.spec.ts tests/e2e/difficulty.spec.ts
```

難度驗證腳本逐 tick 執行真正的模擬與合法買點指令。每關比較均衡爆破、連鎖穿透、控場灼燒三套隊伍，五個固定種子 `101,211,307,419,521`，合計 990 場。自動隊長使用遊戲本身的 `shouldAutoCast`；每場在取得至少 4 點後驗證一次快照還原。

通過條件：每關簡單與困難至少各有兩套策略通過全部五個種子；每項限制挑戰至少有一套策略通過全部五個種子；沒有未結束的戰局，通關配點符合預算。失敗的策略保留於報告，不將其刪除或當作真人勝率。

`--legacy` 可用相同隊伍與策略比較舊平衡；`--manual` 使用固定的蓄力／牆前敵群觀察規則延後施放，最多保留 12 秒。這只是可重現的操作策略，不能代表最佳人類操作；等待錯誤時機也可能比自動施放更差。

瀏覽器測試檢查 320／1440 像素的波次情報、最終關的正常配點與 3× 首領戰、自動隊長演出及通關結算。桌面瀏覽器數據不等同實體手機效能或真人通關率。

## 最終驗收結果

全部 66 項關卡／模式驗收通過。990 場中 929 場通關；61 場失敗保留於原始資料。五個種子、三套隊伍及前述自然成長條件適用於整份結果。

| 模式 | 通關／模擬場數 | 平均結束塔血 |
| --- | ---: | ---: |
| 簡單 | 225／225 | 60.8% |
| 困難 | 222／225 | 47.9% |
| 四人挑戰 | 145／180 | 33.4% |
| 禁隊長技能 | 161／180 | 39.6% |
| 兩終極挑戰 | 176／180 | 51.6% |

平均值包含失敗場次；不是玩家勝率，也不是每套構築保證的結果。簡單／困難的每關均至少兩套策略通過全部五個種子，各限制挑戰至少一套。

以完全相同的隊伍、配點與五個種子比較舊平衡，困難平均結束塔血由 54.9% 降至 47.9%。這是整體比較；特定反制構築在個別關卡可能比舊版更有利。

另以一個種子測試三套只分散投資基礎節點的策略：困難通關由舊版 35／45 降為新版 20／45，簡單由 45／45 降為 38／45。完成關鍵路線與選對投入順序的差異因此更明顯；不代表所有分散配置都無效。

固定延後施放的 60 場手動策略測試通關 55 場；同組自動策略通關 57 場。手動保留技能在部分組合有優勢（S12 連鎖隊平均剩餘塔血約 66%，自動約 59%），但盲目等待也會降低表現。沒有要求玩家必須手動操作才可通關。

規則與存檔 370 項、離線單元 18 項、Chromium／WebKit 六項瀏覽器測試、正式建置、素材完整性及兩種瀏覽器的正式版離線驗證全數通過。完整混合敵群測試同屏峰值 39 隻；原有 120 敵人、400 彈體、12 場域的純模擬壓力測試 p95 約 10.1 ms，低於每步 33.3 ms 預算。

- Chromium：最終關 3× 首領戰通關；p95 幀時間 26.1 ms。
- WebKit：最終關 3× 首領戰通關；p95 幀時間 18.0 ms。

上述幀時間來自桌面自動化瀏覽器，門檻為 33.3 ms；不宣稱兩者均達穩定 60 FPS，也未取代實體手機驗收。
