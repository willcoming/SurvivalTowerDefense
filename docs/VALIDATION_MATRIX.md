## 10. 完成審計方法

每筆真實結果以本文件 caseId 關聯，記錄 `passed` / `failed` / `not-run` / `external-pending`。同一個測試可覆蓋多個ID，但只能對實際斷言、操作或視覺檢視過的範圍報passed。工程交付時需彙總所有R/S/B/A案例；未跑的工程門檻不能用「已列測試」或「建置成功」替代。X01/X02可明確外部待驗證而不阻止本地工程版交付。
