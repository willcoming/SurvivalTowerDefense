# 隊長技能演出加強

> 歷史更新紀錄：本頁描述該次功能與當時量測，內文的新局版本、選卡規則、演出時長及素材數量不全部代表現況。現行 0.3.0-dev.1 規格與驗證請見 [文件總覽](README.md)、[介面與音訊](UI_AUDIO.md)及[交付報告](DELIVERY.md)。歷史命令對應當時的腳本；目前重現方式見 [測試策略](TEST_POLICIES.md)。

技能的 0.5 秒特寫與特效原本很快淡出，容易混入普攻。本次將角色特寫延長至 **1.2 秒**、戰場特效延長至 **1.5 秒**。手動與自動施放使用同一段演出。延長的是呈現時間，傷害、護盾、冷卻、控場與規則 tick 持續依原本機制運作。

特寫位於戰場 y=323–435，使用較大的角色頭像、29px 技能名稱、角色專屬邊框色，以及一次滑入／淡出。戰場特效先立即爆發，保留主要輪廓至約 0.9 秒，再淡出；不需要等演出結束才能操作。

| 技能 | 視覺辨識 |
| --- | --- |
| 璃音・天際掃射 | 四道傾斜掃射光束、瞄準環與亮芯命中 |
| 雷娜・電磁靜默 | 全場多層電網、掃描光帶與電磁輪廓 |
| 凜月・核心貫擊 | 粗狙擊光束、核心爆閃、交叉斬線及鎖定環 |
| 米菈・時差力場 | 三層重力環、旋轉核心與上推箭紋 |
| 芙蕾・熔星空投 | 垂直空投光柱、放射爆焰及擴張衝擊環 |
| 希雅・棱鏡防幕 | 防線前方展開六角盾片、無人機投射與明亮光幕 |

希雅的六角盾片與光幕表示防線護盾啟動，實際仍為 **220 點護盾、8 秒有效戰鬥時間**；1.5 秒演出是啟動提示，剩餘護盾仍由 HUD 與防線護盾條呈現。盾片在特寫上方展開，避免主要視覺被遮住。其他技能的演出同樣是視覺提示，並非新增彈體或額外傷害。

## 計時與可讀性

- 演出使用既有可暫停的實際時間，1× 與 3× 都是 1.2／1.5 秒。
- 手動暫停、選卡與背景暫停會凍結動畫；重新載入不重播舊技能。
- 敵人預警幾何／文字維持 90／100 層，高於技能 9 層、特寫 20 層。特寫保持在下方，頂端預警區保持開放。
- 低特效模式取消特寫位移，減少電網、爆焰與盾片數量，仍保留技能主體。沿用事件數量上限。
