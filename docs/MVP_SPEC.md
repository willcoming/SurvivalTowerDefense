# 《星骸防線：黎明反攻》單人 MVP 規格

> 本文件保留 0.3 基礎規格／驗證。0.4 現行獎池、八人、15 關、186 節點及新增驗證以 [星際夏日更新](COLLECTION_UPDATE.md) 為準；下文的六人、三關、無招募等描述不再代表現行完整範圍。

內容版本：**0.3.0-dev.1** · 同步日期：**2026-09-05** · 手機直向網頁遊戲

組成最多五人的美少女防衛隊，運用外星改良科技、角色分工與自由技能樹，在六至八分鐘內守住地球反攻據點。本頁為現行產品規格；初版數值、三選一與 A/B 設計保存在 [原始規格](history/MVP_SPEC_INITIAL.md)。

## 1. 目標與範圍

核心體驗是看懂敵人威脅，選擇合適的角色與局內技能搭配，再透過調整構築改善戰果。通關解鎖後續關卡、故事和挑戰，不累積永久戰力。

| ID | 現行需求 |
| --- | --- |
| R01 | 可實際開發驗證的單人 MVP；手機直向網頁，桌面也可遊玩。 |
| R02 | 近未來地球遭外星入侵，熱血反攻的日系美少女科幻。 |
| R03 | 六位成年角色全部開放，自由選擇 1–5 人及一名隊長。 |
| R04 | 每人一把專屬外星改良武器，依定位設計 2–3 條技能樹，共 14 條。 |
| R05 | 全部技能樹初始可查閱；局內花點取得節點，不需刷取解鎖。 |
| R06 | 固定陣地與自動射擊，玩家主要操作自由配點與隊長技能。 |
| R07 | 成功局有效戰鬥時間六至八分鐘，配點與暫停不計時。 |
| R08 | 每 60 XP 取得 2 點，直接從完整樹選擇；每次必須花完才能繼續。 |
| R09 | 三個可重玩關卡，以組隊與構築過關，無資源農度門檻。 |
| R10 | 局外解鎖新關卡、故事與挑戰；沒有角色永久升等或戰力加成。 |
| R11 | 免登入，進度與完整戰局自動保存在目前瀏覽器。 |
| R12 | Q 版戰鬥角色、日系立繪及可辨識的武器、技能與敵人動畫。 |
| R13 | 同基礎戰力比較不同構築；保留實驗證據，真人理解度另行驗證。 |
| R14 | 只有隊長提供手動技能，可設定自動施放；開局先完成完整冷卻。 |

R04–R08 依後續定案更新，取代原 12 路線、三選一、重抽與保底設計。AI 已完成規則、流程、存檔、畫面與自動化驗證，工程狀態見 [交付報告](DELIVERY.md)。

MVP 包含六人、14 條角色樹、138 個角色節點、12 個共用節點、25 個角色終極、三關、八種普通／精英敵人和三位 Boss。沒有多人、帳號、雲端存檔、抽卡、體力、商城或永久養成。裝備掉落延後至技能樹平衡驗收後另提設計。

## 2. 世界觀與關卡

外星「群巢」入侵近未來地球，將城市改造成採集前哨。六位成年女性組成晨星防衛隊，回收受損的共鳴核心，將外星科技轉譯成人類能操作的武器。戰場資料提供局內改造點數；每局結束後臨時構築解除，下次可重新搭配。

| 關卡 | 目標 | Boss／主要反制 |
| --- | --- | --- |
| S01 晨曦撤離線 | 保護車站能源閘門，掩護撤離 | 群巢播種者：清召喚物、打斷蓄力 |
| S02 零點研究所 | 守住轉譯主機，破解護盾頻率 | 棱盾監工：破盾、利用曝露窗口爆發 |
| S03 墜星反攻 | 封鎖降落艦核心，阻止再啟動 | 降臨核心：處理蓄力、半血護盾與曝露窗口 |

對話可跳過並於圖鑑回看，不計入戰鬥時間。失敗回饋引導調整隊伍、技能與施放時機。故事及素材採原創設定；使用者提供的 HOTDZero 原稿僅作早期玩法架構參考，其商業數據不作本專案驗證依據。

## 3. 核心流程與時間

選關／看敵情 → 編隊與指定隊長 → 自動戰鬥 → XP 達標自動開樹 → 預覽並依序確認花完 2 點 → 繼續戰鬥 → Boss → 結算、調整搭配與重試。

- 普通波次共八波，起點為 0、45、90、135、180、225、270、315 秒；Boss 在 360 秒登場。
- 擊敗 Boss 並清除剩餘敵人才能勝利；防線 HP 歸零或 480 秒仍未完成即失敗。勝利前先完成已賺到的技能點配置。
- 模擬固定 30 Hz；1×、2×、3× 同步加速敵我移動、攻擊、冷卻及波次。全程 3× 的六至八分鐘戰鬥約需兩分至兩分四十秒現實時間，另加暫停及演出。
- 背景、手機橫放或持續畫面中斷超過 500 ms 會暫停；返回後由玩家確認繼續，不補算離開期間的傷害。
- Boss 出場固定 1.5 秒現實時間，凍結所有模擬與冷卻。隊長特寫約 1.2 秒、戰場特效約 1.5 秒現實時間，單純技能演出不暫停戰鬥。

## 5. 自由配點與共用技能

每 60 XP 得 2 點，共 12 次、24 點，對應全局 720 XP。發點依經驗值，並非固定時間里程碑。選項由完整技能樹提供，取消新版的隨機三選一、聚焦和重抽。

點節點只預覽，按「確認取得」才花 1 點。可跨角色、跨樹並投資共用技能，沒有洗點。每次兩點必須全部花完，關閉或 Escape 不能留點返回；「暫存離開」可保留半途配置，恢復後先花完剩餘點數。多組升級依序處理。

樹的寬度、前置交會和終極數不強制對稱。必須先取得指定前置且在同樹投入四個節點，才可用第五點取得終極。每角色最多一個、全隊最多三個；「最多兩終極」挑戰為兩個。選終極不移除其他普通節點，仍能跨樹投資。

共用技能為防線工程、緊急應變、戰術協同三條路徑，每條四節點，全為被動或自動觸發，不占終極名額，不增加手動技能按鈕。詳細規則見 [自由技能樹規格](FREE_SKILLS.md)；所有前置、數值和 25 個終極見 [150 節點表](FREE_SKILL_NODES.md)。

XP 達標若遇敵人蓄力，最多延後 60 tick（兩秒有效時間）開樹，避免連續預警阻塞升級；Boss 登場則等演出完成。平時也可開樹唯讀查看，期間暫停，關閉後返回原先的運行／暫停狀態。

## 6. 固定敵情、範圍與狀態

開局以種子生成並保存八波計畫。第一波標準編成，其餘可為標準、疾行、重甲或屏障。第 3／5／7 波各抽一項事件，可重複；從第二波起，每波最多替換兩個基礎敵人為該關既有特殊敵種，保持 XP 與出場時間。

| 變體／事件 | 對所屬波次敵人的實際效果 |
| --- | --- |
| 疾行編成 | 移速 +15%、生命 −10% |
| 重甲編成 | 裝甲 +8 個百分點、移速 −10% |
| 屏障編成 | 生命 −8%，額外護盾為調整後最大生命的 15% |
| 離子共振 | 額外護盾為最大生命的 10%；受到的電弧傷害 +25% |
| 熱流裂隙 | 裝甲 +5 個百分點；受到的熱能傷害 +25% |
| 重力潮汐 | 移速 +10%；受到的擊退與牽引 +35% |

變體與事件可同時作用，Boss 本體不套用。情報使用已保存計畫，列出下一批尚未部署敵人所在波次及其下一波：名稱、剩餘數量、帶盾／帶甲單位占比、變體、事件及反制。已出場敵人不混入剩餘部署數；刷新與同種子重試不重抽。

武器只對實際射程內的合法目標開火。範圍圈與實際幾何對齊，貫穿、連鎖、延遲子爆炸及位移按各自規則命中。燃燒、緩速、暈眩、曝露與護盾以敵人真實狀態呈現，到期即移除；Boss 控場限制由模擬層統一處理。節點帶來的傳火、碰撞、回流、微型導彈等也需產生實際戰鬥效果。

## 7. 畫面與操作

手機一次查看一名角色的一條樹，可切換角色和樹分頁。節點間顯示真實前置連線；已取得、可取得與鎖定均有文字狀態，鎖定節點可預覽理由。樹內可捲動，確認區固定在下方，敵情可展開／收起。

六人具備可辨識的瞄準、射擊、後座與各武器彈道、命中特效；八種敵人與三位 Boss 有移動／行動、受擊和死亡演出。25 個終極以既有角色與武器素材搭配程序特效呈現，不代表新增 25 套專屬插畫動畫。六種隊長技能、Boss 登場與敵人預警在 3× 下保持可讀，預警使用最高圖層。

點角色頭像查看射程；空白鍵施放隊長技能，Escape 暫停或關閉唯讀樹，不能跳過必須消費的配點。低特效保留主要命中、狀態和警告。音樂與音效可分別調整並保存，詳見 [介面與音訊](UI_AUDIO.md)。

## 8. 本地存檔與相容性

使用目前瀏覽器、目前網址來源的 IndexedDB；每五秒現實時間及重要操作自動保存。保存請求先凍結快照再依序寫入，revision 防止舊分頁覆寫較新的紀錄。損壞、儲存失敗與衝突顯示恢復流程；不自動清空使用者進度。

戰局保存 tick、RNG、敵群計畫、敵人與狀態、彈體／場域、延遲事件、隊長冷卻、已購節點、XP／點數、配點進度、Boss 演出與操作紀錄。載入先暫停，不能藉刷新洗敵情、重置冷卻或重領點數。背景與方向暫停遵守原配點限制。

0.3 新局使用本文件；0.2 的 70 節點三選一，以及 0.1.0-dev.2／dev.3 的 A/B 舊局維持原內容規則。關卡進度與速度、自動技能等偏好保留。跨瀏覽器、來源網址或裝置不同步，清除網站資料會清除存檔。

## 9. 驗收與後續

目前工程證據：254 項規則／存檔測試通過；瀏覽器 150 案例中 147 通過、3 個 WebKit 不適用桌面效能案例跳過；1,500 場正式配對模擬全部通關、50 個命令重播一致，另有 200 個合成診斷探針。詳見 [驗收矩陣](VALIDATION_MATRIX.md)與[交付報告](DELIVERY.md)。

1,500 場採固定代表性隊伍，不能推論所有搭配平衡或任意單人構築可過關。不同技能樹是否需要相同總數，繼續依同投入下的機制價值、隊伍貢獻與真人選擇研究判斷，現階段保留不對稱。

真實 iPhone／Android、實際 Safari 應用程式及五位真人理解度與趣味性仍待驗證。真人目標是至少 4/5 位在第一次失敗後能提出具體搭配調整，且沒有被引導去刷永久戰力；這是目標，尚非成果。後續執行順序見 [執行計劃](EXECUTION_PLAN.md)。
