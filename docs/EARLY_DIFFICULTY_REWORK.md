# 前期難度調整（balance 7）

依 `codex-rework/09-EARLY_DIFFICULTY_REWORK.md` 實作。新戰局使用 balance 7，經驗仍為 version 4；舊戰局沿用原平衡版本，不在讀檔後換成新敵軍。

## 最終規則

- 主線敵軍基數為 `18 + floor(rank × 0.4)`；首領耐久倍率為 `min(1.3, 0.65 + rank × 0.05)`。S01 倍率從 0.43 升至 0.70。
- S01 波次敵人由 140 增至 202（+44.3%），第一波由 13 增至 19（+46.2%）；仍為 10 波、42 名入場護衛與 20 點技能預算。
- S01 首領從固定座標 `(290,115)` 進場並維持該位置。相對既有攻城傷害再乘 0.50，四人／禁終極挑戰乘 0.45，讓較長的首領戰能承受數次攻擊。
- S03 首領耐久倍率由 0.59 升至 0.80，單次攻城傷害相對既有設定乘 0.70，保護原本可通關但缺少持續控場的自由配置。
- S02～S12 增加的敵軍以普通兵補足，各波特殊兵數不超過 v6；四人／禁終極挑戰每波重甲最多 1 名。保留總敵數、既有編隊時序與進階難度 12% 數值緩和。
- 外傳與百波的敵軍、首領位置和倍率維持 v6。
- 技能樹、武器、控場、升級 XP 公式、每波 XP、點數價格與總預算不變；自動測試隊伍與策略不變。參數僅依關卡／模式選取，不依種子、隊伍、HP 或勝負動態調整。

只提高首領 HP 會延長控場隊的壓制時間，卻讓缺少控場的隊伍承受過多傷害。因此使用固定進場位置增加首領出手機會，並降低單次攻城傷害；S02 之後則保留特殊兵上限，避免提高總人數時連帶堆疊裝甲威脅。

## 驗證結果

先執行 `npm run test:simulation`，再執行 `npm run test:rules`。

- 關卡模擬：226／226 勝利，包含 198 個主線／外傳難度案例、18 個原始四人隊案例與 10 個造型案例；全部存檔還原成功，技能點投入符合各關實際預算。
- S01 Easy 的正式種子 101／211／307：HP 由 1000 降至 393.2785；各承受 3 次正常首領攻擊，實際損失 606.7215 HP（60.7%）。平均通關時間從 183.34 秒增至 231.10 秒。
- S01 四人挑戰的三個正式種子均剩約 251／1100 HP；限兩次進化模式最低剩約 168 HP。S01～S06 原始四人隊 18／18 勝利，最低剩 275 HP。
- 額外的 S01 種子 401／503／607，各五種模式及原始四人隊共 18／18 勝利。這批 Easy 仍有滿血案例，因此不保證每個種子都殘血。
- 相容性與規則：保留 66 個 v6 設定的 profile／戰鬥快照雜湊，並驗證還原後繼續模擬一致；另檢查新編隊與實際出怪數量、首領生成位置、全部角色與造型的技能價格／效果和 XP 不變。
- `test:rules`：50 個檔案、970／970 項通過；型別檢查、角色動態素材驗證與正式建置通過。
- `test:simulation:free`：最終整合版 960／960 勝利，保住全部 955 個原勝利案例並改善 5 個原敗局；960／960 存檔還原、32／32 完整回放雜湊比對、全部技能預算檢查通過。S01／S02／S03 各 320 場，最低 HP 分別為 65.038、26.4125、110.0905。

自由技能驗證另外保存 v6 原先 955 個勝利案例的識別資料。完整檢查必須涵蓋並保住每一個原勝利案例，不能只靠總勝率或新增勝利抵銷回歸。

固定測試隊伍的結果用於驗證難度調整及回歸，不代表任意隊伍或技能配置都能通關。
