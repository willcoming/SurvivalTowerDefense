# 作戰選關與編隊流程草案

日期：2026-09-08。狀態：第 2 張修訂版已套用本地編隊總覽，作戰選關與每局獨立規則已實作；未部署。

## 目標

以 390 × 844 為主要設計尺寸，主要操作一屏可見。保留既有深藍、青色、金色與角色插畫風格。作戰分頁負責選擇關卡，編隊分頁展示及調整小隊，兩者各有清楚用途。

## 已確認的分頁與戰鬥規則

- 作戰：選擇章節及關卡，查看關卡資訊，再開始該關戰鬥。
- 編隊：採用第 2 張的小隊肖像排列與隊長大立繪，先展示目前正式小隊。
- 每次關卡都是獨立的一局，跳出後再次進入必須重新開始；移除跨離場的本局續玩及「繼續行動」入口。
- 重新開始的是本局戰鬥狀態，不重置角色收集、已確認編隊與既有永久養成／通關紀錄。
- 保留作戰、編隊、招募、圖鑑、紀錄五個既有導覽入口。

舊三張探索图的 S06、04:03 與「繼續行動」只是被本輪回饋否定的示意，不能作為後續行為規格。一般戰鬥內暫停不等同離場；離場及重新進入的程式路徑在實作時需一併檢查。

## 第一步：編隊總覽修訂

- 頂部五位目前隊員的直式肖像並列，姓名、小隊人數與隊長標記清楚可見。
- 中央呈現隊長大立繪與角色資訊，使用有景深、光源與材質細節的插畫；不使用俯視戰鬥地圖或過於簡單的漸層背景。
- 移除關卡摘要、作戰計時及續玩按鈕；下方主要按鈕為「編隊」。
- 底部分頁選中「編隊」，不在總覽直接修改正式配置。

## 後續步驟：編隊編輯

1. 先呈現目前出戰小隊及隊員資訊。
2. 按「編隊」才進入編輯。
3. 編輯操作先保留在草稿，不立即改動正式小隊。
4. 最後確認，一次套用完整配置。

編隊草稿與本局戰鬥狀態分開管理。「編隊暫存」不表示保留離場後的戰鬥進度。草稿離頁後的保存期限留待編隊步驟定義；已確認的編隊供下次新的一局使用。

實作補充：草稿在同一次頁面開啟期間跨遊戲分頁保留，尚未確認的草稿不寫入永久存檔。依最新要求，編輯頁不提供「暫存返回」，只保留「確認編隊」。

## 後續實作驗收

- 390 × 844 一屏可見主要操作；較窄或較矮螢幕不遮擋按鈕。
- 編隊總覽可辨認隊長、隊員人數及目前隊員，按「編隊」才進入編輯。
- 作戰分頁提供選關，不以編隊總覽取代選關。
- 離開關卡後再次進入從本局初始狀態開始，不出現「繼續行動」。
- 過期的本局快照不得自動恢復，永久收藏與養成資料不得因此重置。
- 編隊草稿不在逐次點選時改動正式配置。
- 按鈕尺寸適合觸控，文字不截斷，主操作不被底部導覽覆蓋。
